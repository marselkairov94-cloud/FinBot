# FinBot: Цифровой помощник на базе адаптивных алгоритмов для планирования карманных расходов и формирования финансовой грамотности подростков

Проект для защиты на научном конкурсе (9 класс).
Стек технологий: Python 3.x, aiogram 3.x, pandas, FSM.

---

## Описание проекта

FinBot — это прикладная информационная система (Telegram-бот), созданная для решения проблемы импульсивных карманных трат и раннего истощения бюджета среди подростков.

В отличие от стандартных приложений для учета расходов, которые просто регистрируют траты постфактум, FinBot применяет адаптивные предиктивные алгоритмы:
1. Переводит деньги во время: показывает, на сколько дней конкретная покупка или перерасход отодвигает достижение личной цели (например, покупку наушников или смартфона).
2. Динамически пересчитывает дневной лимит на завтра: перераспределяет оставшийся бюджет недели, помогая пользователю не остаться без денег до следующего поступления.
3. Анализирует импульсивность: отслеживает спонтанные покупки и оценивает их суммарное влияние на бюджет.

## Математическая модель и алгоритмы

### 1. Онбординг и расчет базового лимита (Накопить на цель)
* Обязательный взнос в фонд цели в неделю (S_goal):
  S_goal = Стоимость_цели / Срок_в_неделях
* Доступный бюджет на жизнь в неделю:
  Бюджет_жизни = Недельный_доход - S_goal
* Базовый дневной лимит (L_day):
  L_day = Бюджет_жизни / 7
* Предиктивная проверка реальности цели:
  Если L_day < 100 ₸/день, алгоритм рассчитывает минимально реалистичный срок:
  W_realistic = ceil(Стоимость_цели / (Недельный_доход - 700)) недель

### 2. Динамический пересчет лимита на завтра при перерасходе
* Перерасход за день:
  Delta = Траты_за_день - L_day
* Новый дневной лимит на завтра (L_tomorrow):
  L_tomorrow = (Остаток_бюджета_недели - Delta) / Осталось_дней_в_неделе

### 3. Предиктивный расчет сдвига цели (перевод денег во время)
* Сдвиг цели из-за перерасхода:
  Сдвиг (дней) = ceil(Delta / (S_goal / 7))

## Структура проекта

```
finbot/
├── config.py                 # Настройки, пути, валюта (₸), лимиты
├── main.py                   # Точка входа для запуска бота
├── requirements.txt          # Список зависимостей
├── .env.example              # Пример файла переменных окружения
├── README.md                 # Документация проекта
├── database/
│   ├── models.py             # Датаклассы UserProfile (с никнеймом) и ExpenseRecord
│   └── storage.py            # Хранилище профилей (JSON) и логирование (CSV)
├── services/
│   └── algorithm.py          # Математические и предиктивные расчеты
├── handlers/
│   ├── common.py             # /start (запрос никнейма), /status, /reset, /help
│   ├── goal_onboarding.py    # Сценарий: Накопить на цель
│   ├── limit_onboarding.py   # Сценарий: Контролировать лимит
│   └── expenses.py           # Ввод расхода (число -> категория -> импульсивность)
├── keyboards/
│   ├── reply.py              # Главное меню бота
│   └── inline.py             # Быстрый UI (категории, импульсивность, выбор срока)
├── data/
│   └── expenses_dataset.csv  # Логи расходов пользователей для исследования
└── tests/
    └── test_algorithm.py     # Модульные тесты формул и сценариев
```

## Установка и запуск

1. Переход в каталог проекта:
   ```bash
   cd C:\Users\marse\.gemini\antigravity\scratch\finbot
   ```

2. Установка зависимостей:
   ```bash
   pip install -r requirements.txt
   ```

3. Настройка токена:
   Создайте файл `.env` на основе `.env.example`:
   ```ini
   BOT_TOKEN=ВАШ_ТОКЕН_ОТ_BOTFATHER
   ADMIN_IDS=ВАШ_TELEGRAM_ID
   ```

4. Запуск бота:
   ```bash
   python main.py
   ```

5. Запуск тестов:
   ```bash
   python -m pytest tests/test_algorithm.py -v
   ```
